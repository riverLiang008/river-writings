# “到德国去”

2026.01.12

并不新奇的问题：我究竟想要什么样的生活？我究竟要去哪里？

几个不出意料的版本：

A 在大城市打拼，升职。当上年收入几十万的小领导。

B 找一个大城市土著结婚。婚姻生活。

C YOLO生活<sup id="note-ref-1"><a href="#note-1">1</a></sup>。去多个国家旅行。未婚。无存款。

这些马上可以从“认识的”某个人身上找到的“范本”，似乎各自有各自“成功”的方式。但似乎都不是我想要的。似乎都是我恐惧的。

昨天远走德国工作的念头在我脑海里冒出来之后，我就止不住在想这个问题。是的——世界上没有乌托邦。困境如影随形。或许在德国待了几年之后我仍然一无所有。于是问题浮现——在“逃离”叙事的背后，我真正追求的是什么？我想要以怎样的方式度过我的时间？这种方式不是抽象的，而是——我选择在哪里、怎么样度过每一天，怎么样面对真实的困境？

卡尔维诺在《树上的男爵》中设计出了一条完整的通往自由的路；黑塞在《悉达多》中设计出了一条通往“完满”的路。但它们是抽象，是寓言，是人类尚未实现的一种生活方式的雏形。

所以我要问自己，你究竟想过什么样的生活？

似乎答案并不在世界上的任何一个地方，答案在我走向自己的这条路上。我有时能够看到它，有时它又消失在我的视线里。

我决定开始找德国的工作，这就是答案。它存在于当下，也存在于很久之后回首之时。如果我最终没有去德国，那么这个念头就像一个翻不起多少涟漪的小水花。湖面又回到平静。

我的答案抽象又明确——我想要把意义塞进我的时间里——像把书一本本摆满书架。然而社会现实却将我的时间切割成无数个碎片，于是我只能像一个拾荒者——捡起其中极少的一些，将它们打磨成我喜爱的形状，摆在窗台上。这一刻，我理解了电影《肖申克救赎》中安迪将他打磨的石头摆在窗台上的隐喻。

我并不责怪“现实”，因为那是我的一部分。只是，当我筋疲力竭、想要挣脱而不得的时候，我也会咒骂它。

咒骂它。于是又投身其中。未来？未来并不存在。只有我脑海中浮现出的，停留在我心念中的一个“到德国去工作”的影子。它可能实现，也可能不会。<sup id="note-ref-2"><a href="#note-2">2</a></sup>

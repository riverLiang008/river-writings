# 十二点的蓝色自行车

<p>时刻A：从公司的门走出来，左手边有一辆蓝色自行车。门紧挨着中国移动营业厅。</p>

<p>时刻B：从公司的门走进去，蓝色自行车已经不在了。门紧挨着中国移动营业厅。</p>

<p>截取的一段时间的两端是两个相同而又不同的空间。一个人从门内匆匆走出来，一个人匆匆走进去。同一个人与自己擦肩而过。神注视这一切。</p>

<p>骑上自行车，手表指示正午十二点，太阳按理升到最高点，但这是一个名为北京的地点的太阳时，不是这个手表的。手表既不是时间本身，也不是时间的载体，那它是什么呢？手表什么也不是。</p>

<p>骑上自行车，踩上踏板，空间开始移动。但事实是空间并没有移动。空间沿着时间移动，空间相对于空间却不动——中国移动营业厅没有动，但是自行车不在了，即使自行车还在也改变不了什么，所以空间移动了。</p>

<p>周遭的景致：房子，树，人都反射着阳光，所有的事物都是阳光的幻影。阳光消失了，所有的事物也就消失了。不，它们还在那里，但是它们却消失了。</p>

<p>声音？听到声音了吗？此时有千千万万种声音，A听到了声音I，B听到了声音II，C听到了声音I和II，D听到了声音I和II和III……所以只有一种声音（对A来说），只有两种声音（对C来说），只有三种声音（对D来说）。万物皆静默，没有一种声音。</p>

<p>自行车沿着空间的某一条线缓缓行驶。在中国移动营业厅看来，自行车渐渐变小，最终消失。自行车没有消失，它一直存在于它所存在的世界，它被骑着它的人感知到，它被注视着，观察着，它被一束意识的光照亮，显现出它的形貌——蓝色的，两个轮子，黑色车筐和把手。自行车消失了，在时间之中消失，再也没有人能够找到时刻A里的自行车了，接着(A+dA)时刻的自行车也消失了，接着(A+2dA)也消失了，接着(A+3dA)也消失了，在永恒的消逝之中，没有什么能够幸免，什么都不存在，什么都在时间里存在。神在背后注视着这一切。</p>

<p>远处有一个黑点，变大，变大……直到意识的光完完全全罩住这个物体，一个名为“桥”的物体。但是它从来没有名字，过去不曾有，未来也不会有。那“桥”是什么呢？“桥”什么也不是。但是那是一座桥。</p>

<p>江面的水浮起来了，阳光被切成了无数的碎粒，那一刻一片宁静的蓝色进入了一个心灵。从此，无序的状态被打乱，意义升腾起来了——意识和被意识照亮的物体之间的抚摸和安慰——那一座桥，和那片蓝色的水和这个心灵的所有过去和未来将永恒存在，它们不再仅仅是一座桥和一片铺满了阳光细粒的水，它们变成了一种无可名状的感觉，和一种若隐若现的启示。</p>

<p>路在尽头处消失，正前方出现了一个巨大的门口，像是某种货运的仓库。许许多多的自行车、电动车、摩托车都向着那个口流去。很难说是这些载具向着那个巨大的口流去，还是载具上的人向那个口流去，还是这个口吸纳了这些载具和人——就像很难说清是人朝着深渊流动，还是深渊抓住了人。仓库的巨门对于一个从未踏足此地的人来说是未知之境，未知之境就是深渊。</p>

<p>穿过巨门，一个码头出现了，路通向船舱。船行驶的水路被命名为“南码头路”。南码头路上的车、人都是静止的，他们几乎不在他们所处的平面上移动。透过几处透明的窗子，能看到外面浮动的水面。船舱的空间被阳光切割成亮部和暗部。被阳光从45度角照射的人的面部被切割成了奇异的几何形状；阳光垂直射入的人的眼球反射着阳光；那些存在于暗部空间的人并非全然没有阳光，但是他们拥有的阳光非常薄，他们的表情和薄薄一层的阳光一样，在观察者的眼中晦暗不明。随着船体的移动，阳光的角度在不断地变换；阳光切割的空间在不断地流转。封闭空间下的一幅群体木刻版画——尽管并非实体——但却为某人永恒地拥有——进入意识的部分。</p>

<p>舱门打开的瞬间，一瞬，一秒的兆分之一，凝固的时间又鲜活起来。舱门是个巨大的光源，光线像水一样密密地塞满舱体的所有空隙；从某种意义上，在阳光之中和在水中没有什么区别。许许多多的自行车、电动车、摩托车都向着那个口流出。意识退化为物。此刻，只有观察者一个意识。</p>

<p>自行车驶离码头。两旁是郁郁葱葱的春天的绿色——和以往的所有春天一样，和将来的所有春天一样。码头旁有一座汽修站，汽修站里有一个老板娘。老板娘旁边有一条狗。狗旁边有一株杂草。</p>

<p>叫了一辆出租车返回公司，司机是外国人。自行车永远留在了身后的世界，那个从此湮没在滚滚而上的时间的红尘之中的世界。时刻B：从公司的门走进去。</p>

<p>谁能证明刚才的一切发生过，除了某人的记忆？如果记忆只是虚妄的，那么过去将永恒不存在。如果记忆非虚妄，那么灵魂将是永恒的存在，但却非实有。</p>

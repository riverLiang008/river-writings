# 什么都没发生的一天

<p class="chapter-subtitle">记于新加坡留学期间</p>

<p>前言：本篇原本是记录留学一年之中的难忘经历。因为在这一年里，我去了很多地方（相比起我以前的生活来说），地域跨度很大；见识了很多不同的人，不同的背景、国籍、年龄。我学会了很重要的一点就是，无论我如何看待他们，我都不会用我的价值观去审判他们。我还明白了，无论人们看起来有多么的不同，他们都是如此地相似；以及——尽管人们是如此地相似，他们却有很大的不同。这些经历极大地滋养了我，我可以说，我更加“理解”人了；我也更像我自己了。不幸的是很多篇章写着写着就变成了“流水账”，加之我发现我已失去了说出我那些“故事”的耐心。所以只留下《什么都没发生的一天》这一篇。其他的就交给记忆吧！</p>

<p>除了对这个世界的经验、感觉和爱，我们此生别无所获。</p>

<p>从此种意义来看，人永远无法“拥有”金钱；人只能拥有“富有”的感受。我想过如果突然给我1个亿的财富，我接下来的一天会如何度过？答案是，我仍然会按照原来的轨迹度过一天——就目前来讲，我会睡个懒觉，中午十二点起床；给自己做个早午饭，然后做点家务（洗衣服、收拾房间）；接着我会准备laptop、摘抄本、笔，把它们塞进书包。我会步行来到公寓附近的公交站，等待199号公交把我载至NTU的李伟男图书馆。我会选择一个舒服的座位（对我来说通常是角落的位置），根据我当时的心情选择做点自己喜欢的事情。我可能会学点新知识；继续看没看完的电子书，同时做点摘抄；或者像现在这样写写我的随笔、自然也有不得不完成某些任务的时候。</p>

<p>我享受从起床到入睡的所有过程。也许拥有财富之后，我会换一个更好的书包、换一套更大的公寓——但这并不影响我生活的节奏和本质。</p>

<p>所以我觉得自己是一个富有的人——我现在的生活和我拥有一个亿之后的生活没什么两样。并且我实现了自己小时候关于留学的梦想；我通过实习和兼职攒够了几次旅行的资金；同时，在开始第一份正职工作前，我有足够的时间来探索自己。因此我还觉得自己是一个“成功的”人。</p>

<p>说实话，我的人生到此刻为止，才真真正正体会到了幸福和满足。以前的我觉得自己有太多事情需要去完成、有太多的未知需要操心；我时常为自己虚构一个“随时会塌陷”的明天——于是感到恐惧、焦虑，我拒绝人群，我对世界充满了不满，我迷茫、不知所措以至于时常愤愤不平。尽管我看起来和别人没什么两样，但对一个人内心的风暴往往只有他自己知道。</p>

<p>我记得两三年前的某一天我从本科学校的图书馆走出来，当时已是深秋，空荡荡的街道、光秃的树木；一阵阵寒风灌入我的袖口，我收紧了脖子上的围巾哆哆嗦嗦地往前走，我的情绪说不清的低落。我或许也曾为自己虚构了一个拯救者——就像那些深陷低谷无法自救的少女一样，但我也无比清楚地意识到成长是一条无人替代的孤独之旅——更何况“孤独”是人类的宿命、在生命的绝大部分时间里如影随形。</p>

<p>某天下午，我离开公寓准备前往图书馆的时候，那是一个阳光十分明媚的下午，但却并不炎热，而是有着说不清的清爽。我等了很久的电梯，但它一直没来。于是我便在走廊等待。一阵阵风向我吹拂而来，我看到窗外跳跃的树枝和郁郁葱葱的绿叶，沙沙作响。阳光落在邻居家门口摆放的小木桌上，呈现出一种粒粒分明的质感。我忽然想起一个故事：</p>

<p>“在很久很久以前，一个练习冥想的学生去见一位智者。学生开始谈论哲学概念，例如神的本质，但智者却不发一言。学生侃侃而谈，提了许多问题，可智者仍然保持沉默。最后，学生很无奈地问智者为什么不回答他地问题。智者笑了笑，轻轻地说道：‘我一直在回应你，只是你没有在听——神是静谧的。’”<sup>1</sup></p>

<p>不知为何，那个下午明明再普通不过，却久久触动了我的心灵。那一刻我感受到了神对我的教导——在每一个瞬间，全心全意地活着。</p>

<p>下一个轮回我不愿再来。并非由于我的生活有多么糟糕（相反，我感恩我的人生），而是——尽管被这人间的破碎、黑暗和潮湿所触动，我却无能为力。附小诗一首：什么都不做的一天我会温柔地、认真地——久久注视经过我的日落感受光和热铺满全身、渗透每一个毛孔在这一刻，像升起一面旗帜那样升起我的灵魂</p>

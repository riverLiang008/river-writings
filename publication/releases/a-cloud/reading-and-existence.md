# 不为表演的阅读，不为理解的存在

<div class="chapter-preface"><p>前言：这是大学期间某一次上台发言的演讲稿。这篇稿子背后是一个令我非常难忘的小故事。起因是我在学校图书馆有着超长在馆时间和丰富的图书借阅量、荐购量，于是被学校颁发了一个“阅读之星”的小奖状，并作为学生代表演讲。讲稿是在实习回学校的地铁上完成的。尽管它并不涉及任何的政治敏感话题和时论，并且采用了温和的语调，第一稿交上去时，仍然以“不够阳光”为由被学校领导打回来了。于是我让chatGPT自动生成了一版“阳光版”作为第二版。好在与我对接的图书馆工作人员非常喜欢我的稿子，她和学校领导争取了很久之后终于同意在第一版的基础上稍作改动，并最为活动最终的讲稿。两个月后，我从这所学校毕业。于是那就成了我对学校最后的印象。</p></div>

<p>尊敬的老师、同学们：</p>

<p>大家好！我是来自同济大学软件学院大四的一名学生，非常荣幸能够作为阅读之星的学生代表在本次活动上发言。</p>

<p>我对同济大学图书馆有着非常深厚的感情，也不仅仅是因为她优美的自习环境，丰富的图书馆藏量；更因为我与她共同度过了我绝大部分的大学校园时光。同济大学图书馆对我来说就像玫瑰花之于小王子，在过去四年中我和她一起度过了许许多多的日落，她倾听过我，我也倾听过她，她对我来说就是独一无二的。接下来，我想谈谈阅读对于我的意义。</p>

<p>本雅明的《单行道》封面内页的介绍中有这样一段话：“表现出很独特的组织或结构，它是一条街道，从极其陡峭的深度凿开一幅街景的缩略图。”阅读对我来说正是类似于对本雅明式的空间架构的探索。下面我来解释一下其中的含义。</p>

<p>我们可以想象一下：假设我们有一把剪刀，在时间的维度对空间做一个切割，比如以某种方式截取2024年4月18日8点44分12秒的上海和2024年4月18日8点45分12秒的上海，这期间相差1分钟。对比这两个我们截取出来的静态空间，我们发现这期间发生的变化大多数是可以被理解的，譬如某一地铁十号线的列车在这两个空间里位置坐标的欧几里得距离是600米；某个行人从马路一边过到马路对面。这没什么稀奇的。<sup class="note-ref"><a id="ref-1" href="#note-1" role="doc-noteref" aria-label="注释 1">[1]</a></sup></p>

<p>但是如果我们将截取的时刻在时间轴上的距离拉的很长，比如1904年4月18日8点44分12秒和2024年4月18日8点44分12秒，我们就会发现这期间各种量变和质变复杂得让人难以理解，不用说这期间还充斥着种种偶然和必然的混杂。<sup class="note-ref"><a id="ref-2" href="#note-2" role="doc-noteref" aria-label="注释 2">[2]</a></sup></p>

<p>大家注意一下，神奇的地方就在这里，明明后一个空间是由前一个空间演进而来的，但是只要时间间隔拉的稍微长一点，我们就失去了我们原本十分“自信”的理解。这是为什么呢？</p>

<p>其中一个解释是，这个世界不仅有我们惯常所能看到的我称之为广度的时间和空间两个轴，它还有深度。这个深度意味着所有的事物，包括我们自己，都在一个秘密的地方，一个远离时间和空间的地方暗自生长着，所以才会表现出，就像我前面所说的，一个世界从它的过去走来，又成为它将来的样子。</p>

<p>阅读，或者文字的意义正在于此——它使得我们的意识得以突破线性的时间和空间，从而达到永恒和无限。</p>

<p>这里蕴含了这样一个构想：即个体意识和这个世界同样广阔和无限。但是凭借直觉，我们可以猜想到个体意识的广阔和无限并不是天然的、固有的，而是潜在的、可能性的。也就是说生命有无限的潜能，但是生命所能达到的宽阔与深刻离不开个体的努力。而阅读正是对于这种努力的一种尝试。</p>

<p>为什么我要说阅读是一种尝试而非努力呢？因为在网络媒体如此发达的时代，阅读这一种原应是最为纯粹的精神活动，也极有可能沦为一场有意识或者无意识的表演。我所说的“表演”意味着这样一种逻辑：“我在阅读，所以我懂得更多。”这样的逻辑，至少在我看来，是一种意识上的“无明”。也就是说，我们要警惕，阅读的过程中由知识的增多而积累的傲慢，这种傲慢让我们更加远离智慧，而不是更加接近。</p>

<p>当然，我自问，我真的完全摆脱这样的傲慢了吗？回答是，没有。但是我尽可能放下它。</p>

<p>我理想中的阅读是能够被归还于纯粹的精神体验，一次近乎于老子所说的“道”的生命的震颤，如此，我们才能获得清净的智慧，而非芜杂的知识，我们才能有能量去解决现代性的种种问题，比如人与人之间愈来愈深的隔膜；比如社会对个体的天性无处不在的精神压制和暴力，以及生命的无聊和无意义。我想，这书籍能够赠予那些阅读它的人最好的礼物。谢谢大家。</p>
